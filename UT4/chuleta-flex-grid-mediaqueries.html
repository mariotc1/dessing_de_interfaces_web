🔷 FLEXBOX

Activación

.contenedor {
    display: flex;        /* Activa Flexbox */
    display: inline-flex; /* Flexbox inline */
}

Propiedades del Contenedor (Padre)

1. flex-direction Dirección

flex-direction: row;            /* ➡️ Horizontal (DEFECTO) */
flex-direction: row-reverse;    /* ⬅️ Horizontal invertido */
flex-direction: column;         /* ⬇️ Vertical */
flex-direction: column-reverse; /* ⬆️ Vertical invertido */
Ejemplo: Cambiar menú de horizontal a vertical en móvil

2. justify-content Eje Principal

justify-content: flex-start;    /* ⬅️ Inicio (DEFECTO) */
justify-content: flex-end;      /* ➡️ Final */
justify-content: center;        /* ⏺️ Centrado */
justify-content: space-between; /* ↔️ Espacio entre */
justify-content: space-around;  /* ↔️ Espacio alrededor */
justify-content: space-evenly;  /* ↔️ Espacio uniforme */
Visual:
flex-start: [1][2][3]         
center:     [1][2][3]
space-between: [1]   [2]   [3]

3. align-items Eje Cruzado

align-items: stretch;     /* 📏 Estirar (DEFECTO) */
align-items: flex-start;  /* ⬆️ Inicio */
align-items: flex-end;    /* ⬇️ Final */
align-items: center;      /* ⏺️ Centrado */
align-items: baseline;    /* 📐 Línea base */

4. flex-wrap Envolver

flex-wrap: nowrap;       /* ➡️ No envuelve (DEFECTO) */
flex-wrap: wrap;         /* ⤵️ Envuelve en nueva línea */
flex-wrap: wrap-reverse; /* ⤴️ Envuelve invertido */

5. gap Espaciado

gap: 1rem;         /* Espacio entre todos */
gap: 1rem 2rem;    /* Fila Columna */
row-gap: 1rem;     /* Solo entre filas */
column-gap: 2rem;  /* Solo entre columnas */

Propiedades de los Hijos

flex ⭐ MÁS USADO

flex: 1;           /* Crece y ocupa espacio disponible */
flex: 0 0 200px;   /* Tamaño fijo 200px */
flex: 2;           /* Crece el doble que flex: 1 */
Patrón común: 
.sidebar { flex: 0 0 250px; }  /* Fijo 250px */
.main    { flex: 1; }          /* Ocupa resto */
💡 Centrado perfecto con Flex: 
.centrado {
    display: flex;
    justify-content: center; /* Horizontal */
    align-items: center;     /* Vertical */
    height: 100vh;
}

📐 CSS GRID

Activación

.contenedor {
    display: grid;        /* Activa Grid */
    display: inline-grid; /* Grid inline */
}

Propiedades del Contenedor

1. grid-template-columns ⭐ CLAVE

/* Columnas fijas */
grid-template-columns: 200px 200px 200px;

/* Columnas flexibles con fr */
grid-template-columns: 1fr 1fr 1fr;    /* 3 iguales */
grid-template-columns: 2fr 1fr;        /* 2/3 y 1/3 */
grid-template-columns: 250px 1fr;      /* Fija + flexible */

/* Función repeat() */
grid-template-columns: repeat(3, 1fr); /* 3 iguales */

/* Auto-responsive */
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

2. gap Espaciado

gap: 1rem;         /* Espacio entre celdas */
gap: 2rem 1rem;    /* Fila Columna */

3. grid-template-areas Áreas nombradas

.layout {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

Propiedades de los Hijos

grid-column / grid-row

grid-column: 1 / 3;   /* Ocupa columnas 1 a 3 */
grid-column: span 2;  /* Ocupa 2 columnas */
grid-row: 1 / 3;      /* Ocupa filas 1 a 3 */
Ejemplo: Card destacada que ocupa más espacio 
.card-destacada {
    grid-column: span 2; /* Ocupa 2 columnas */
    grid-row: span 2;    /* Ocupa 2 filas */
}
💡 Grid responsive automático: 
.productos {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 2rem;
}
/* ¡Se adapta solo sin media queries! */

📱 MEDIA QUERIES

Sintaxis Básica (Mobile First) ⭐

/* Móvil (base) - 0px a 767px */
.elemento { 
    grid-template-columns: 1fr;
}

/* Tablet - 768px y superior */
@media (min-width: 768px) {
    .elemento { 
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Desktop - 1024px y superior */
@media (min-width: 1024px) {
    .elemento { 
        grid-template-columns: repeat(3, 1fr);
    }
}

Breakpoints Estándar

Dispositivo Breakpoint Media Query
📱 Móvil 0px - 767px Base (sin media query)
📱 Tablet 768px+ @media (min-width: 768px)
💻 Desktop 1024px+ @media (min-width: 1024px)
🖥️ Desktop XL 1440px+ @media (min-width: 1440px)

Características Avanzadas

/* Orientación */
@media (orientation: landscape) { ... }
@media (orientation: portrait) { ... }

/* Hover (dispositivo táctil vs ratón) */
@media (hover: hover) {
    .button:hover { background: blue; }
}

/* Modo oscuro */
@media (prefers-color-scheme: dark) {
    body { background: #000; color: #fff; }
}

/* Reducir animaciones (accesibilidad) */
@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; }
}

🎨 PATRONES COMUNES

Header responsive

/* Móvil: columna */
.header {
    display: flex;
    flex-direction: column;
    gap: 1rem;
}

/* Desktop: fila */
@media (min-width: 1024px) {
    .header {
        flex-direction: row;
        justify-content: space-between;
    }
}

Grid 1→2→3 columnas

/* Móvil: 1 columna */
.grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 1rem;
}

/* Tablet: 2 columnas */
@media (min-width: 768px) {
    .grid { grid-template-columns: repeat(2, 1fr); }
}

/* Desktop: 3 columnas */
@media (min-width: 1024px) {
    .grid { grid-template-columns: repeat(3, 1fr); }
}

Layout con Sidebar

/* Móvil: sin sidebar */
.sidebar { display: none; }

/* Desktop: sidebar visible */
@media (min-width: 1024px) {
    .container {
        display: grid;
        grid-template-columns: 250px 1fr;
        gap: 2rem;
    }
    
    .sidebar { display: block; }
}

💡 TRUCOS FINALES

Comparación Flex vs Grid

FLEX GRID
1 dimensión (fila O columna) 2 dimensiones (filas Y columnas)
Navbar, botones, cards simples Layouts complejos, galerías
justify-content, align-items grid-template-columns/rows
⚠️ Errores comunes en exámenes:
  • Olvidar display: flex o display: grid
  • No poner gap entre elementos
  • Media queries con breakpoints incorrectos
  • No usar mobile-first
  • Olvidar flex-wrap: wrap en cards responsivos
